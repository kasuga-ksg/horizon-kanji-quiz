# 地平線でGO！

Sound Horizon / Linked Horizon の歌詞に出てくる独自の当て字・難読ルビを当てる、非公式のファンメイドクイズです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルドは不要です）。

## 問題の追加・修正

`js/questions.js` を編集してください。各項目の意味はファイルの先頭に書いてあります。

## GitHub Pages で公開する

1. このフォルダを GitHub リポジトリにアップロード（push）する
2. リポジトリの **Settings → Pages** を開く
3. **Branch** を `main`、フォルダを `/ (root)` にして保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 注意

- 本作は非公式のファンメイド作品で、Sound Horizon / Linked Horizon および関係各社とは一切関係ありません。
- 歌詞の長い引用、音源、ジャケット画像などは使っていません。
